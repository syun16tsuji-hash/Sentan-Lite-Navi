# Sentan-Lite-Navi

This is the Sentan_Lite_Navi repository for ID3 at KUAS.

- The `.aia` file is a MIT App Inventor project file.  
- The `.apk` file is an Android application file.  
- The `.pdf` file is a converted version of the presentation slides.  
- The `.pptx` file contains the original presentation slides.
- The `.mp4` files are demonstrations of the application in the `DEMO` folder
